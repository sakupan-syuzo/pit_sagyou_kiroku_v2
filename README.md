# PitRec V2 (Pit 作業記録アプリ)

モータースポーツにおけるピット作業（PIT IN / OUT時刻、ドライバー交代、タイヤ交換、給油など）を、スマートフォンから直感的に記録・管理し、PDFやCSVとして出力できるモバイルファーストのPWAアプリです。

V2では、大会公式のエントリーリスト（PDF）からの自動データ抽出や、複数レース（セッション）の管理、他端末へのデータ引き継ぎ機能など、実践的な機能が大幅に強化されました。電波状況の悪いサーキットでも安定して動作する完全オフライン対応のスタンドアロンアプリです。

---

## 🌟 主な機能

- **エントリーリストの自動解析**: 大会公式のPDF（エントリーリストやピット割当表）を読み込ませるだけで、Car No、PIT No、ドライバー名を自動で抽出・紐付けします。
- **複数レース（セッション）の管理**: 最大5つまでのレース枠（例：SGT、SF など）を個別に管理でき、スケジュールに応じた切り替えが可能です。
- **マルチレーン＆タイマー機能**: 最大5レーンまでのピット作業を同時記録。作業中はリアルタイムな経過時間タイマーが表示されます。
- **連続記録モード**: 短時間で次の作業が入る場合、PIT番号やCar番号を維持したまま次のIN待ち状態へシームレスに移行できます。
- **スマートデータ引き継ぎ（JSON連携）**: 別の担当者にタブレットを渡す際、JSON形式でデータをエクスポートし、AirDrop等で送信可能。インポート時には「受信したデータを自分のどのレース枠に割り当てるか」を選択できる安全なルーティング機能を搭載しています。
- **PDF / CSV の生成と共有**: 記録したデータを車両番号ごとにグループ化した見やすいPDFや、PC集計用のCSVを端末内で生成し、Web Share API を使ってその場で共有（LINE等）できます。
- **完全オフライン対応**: PWAとしてホーム画面に追加可能。入力途中のデータはすべて端末に自動保存（自動バックアップ）されます。

## 📖 使い方（ユーザーガイド）

### 1. 事前準備（データの読み込み）
レースの記録を始める前に、参加車両のデータをアプリに登録します。
1. **「登録」タブ** を開き、「記録対象レース」（例：レース 1）を選びます。必要に応じて「✏️」からレース名を「SGT」などに変更してください。
2. **「📄 PDFから登録」** モードで、エントリーリストやピット割当表のPDFをアップロードします。
3. 表の上のプルダウンから、各列の意味（Car No、PIT No、ドラA など）を指定します（※名前とゼッケンが結合している場合は「Car No + ドラA」を選択）。
4. **「保存して適用」** を押します。手動で微調整したい場合は **「🛠️ 登録済みデータを管理」** モードから修正・追加が可能です。

### 2. 作業記録をつける（打刻）
1. **「作業記録」タブ** を開き、レーンの「PIT No」または「Car No」を入力すると、登録したドライバー情報が自動反映されます。
2. マシンがピットに入った瞬間に **「IN」** を押すと、タイマーがスタートします。
3. 作業中に行われた内容（ドライバー交代、タイヤ交換本数、給油の有無など）を入力します。
4. ピットを出た瞬間に **「OUT」** を押せば記録完了です。（※連続モードONの場合はそのまま次のIN待ちになります）

### 3. 出力と履歴の修正
- 画面下部の **「📋 作業履歴」** に記録が一覧表示され、タップすることで後から時刻や作業内容を修正・削除できます。
- **「出力」タブ** にてセッション名や担当審判員を入力し、「PDF保存 / 共有」または「CSV保存 / 共有」を選ぶことで、記録データを書き出すことができます。

### 4. 複数人でのデータ引き継ぎ
- 記録データを別の端末に送る場合は、出力タブの **「データを送る」** からJSONファイルをAirDrop等で送信します。
- 受け取る側は **「データを受け取る」** からそのファイルを開きます。
- 自動的に「データの引き継ぎ設定」画面が開き、受信したデータを自分のどのレース枠（SGTなど）に上書きするかを選択して安全に合体させることができます。

## 🛠️ 技術スタック

- **フロントエンド**: React 19 / TypeScript / Vite
- **スタイリング**: Tailwind CSS v4
- **状態管理**: Zustand (`persist` によるローカルストレージ永続化)
- **PDF解析**: pdfjs-dist
- **PDF生成**: @react-pdf/renderer
- **PWA化**: vite-plugin-pwa
- **アイコン**: Lucide React
- **ホスティング**: GitHub Pages

---

## 📦 開発環境のセットアップ

Node.js (推奨 v18以上) がインストールされている環境で、以下のコマンドを実行します。

```bash
# リポジトリのクローン
git clone https://github.com/sakupan-syuzo/pit_sagyou_kiroku_v2.git
cd pit_sagyou_kiroku_v2

# パッケージのインストール
npm install

# 開発サーバーの起動 (デフォルト: http://localhost:5173)
npm run dev
```

## 🚀 ビルドとデプロイ

GitHub Pages へのデプロイコマンドです。内部で `npm run build` が実行され、成果物が `gh-pages` ブランチにプッシュされます。

```bash
npm run deploy
```
